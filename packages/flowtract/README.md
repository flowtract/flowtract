# Flowtract

> Developer preview under construction. This package remains private during
> Gate 2 acceptance and is not ready for npm publication or production use.

Flowtract defines explicit, schema-verified contracts for stateful REST API
workflows. Gate 2 adds immutable runtime configuration, isolated scenarios,
Playwright-backed HTTP execution, built-in authentication, state and secret
interpolation, redacted diagnostics, and deterministic cleanup to the accepted
typed operation model. Cucumber integration and the CLI remain later gates.

See the
[canonical v0.1 specification](https://github.com/flowtract/flowtract/tree/main/docs/open-source/v0.1).
