# Flowtract

> Developer preview under construction. This package is private during Gate 1
> and is not ready for npm publication or production use.

Flowtract defines explicit, schema-verified contracts for stateful REST API
workflows. Gate 1 contains the typed operation model and packaging foundation.
HTTP execution, authentication, scenarios, Cucumber integration, and the CLI
are implemented in later proof gates.

See the
[canonical v0.1 specification](https://github.com/flowtract/flowtract/tree/main/docs/open-source/v0.1).
