# Support

Flowtract publishes `0.1.x` as a developer preview. The current release is
`flowtract@0.1.0`; it is not a production- or enterprise-readiness claim.

## Where to ask

- Use [GitHub Discussions](https://github.com/flowtract/flowtract/discussions)
  for questions, ideas, and usage help.
- Use issues for reproducible defects and approved feature work.
- Use [private vulnerability reporting](https://github.com/flowtract/flowtract/security/advisories/new)
  for security issues.

Before filing a defect, include:

- Flowtract revision/version;
- Node version and operating system;
- minimal reproduction;
- expected and actual behavior;
- redacted diagnostics;
- whether the behavior reproduces from a clean project.

Support is best-effort during developer preview. Undocumented deep imports,
modified generated internals, unsupported Node versions, and unapproved
protocols are outside the support boundary.

Maintainers target initial acknowledgment within two business days. Gate 4B
evaluation reports may select public attribution, anonymized aggregate use, or
aggregate count only.
