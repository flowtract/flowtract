# Test contracts in motion

Flowtract provides a typed lifecycle for authenticated, stateful REST workflow
contracts in TypeScript. It combines Zod request/response contracts,
scenario-isolated Playwright sessions, secret-aware state, diagnostics, dry
runs, cancellation, and deterministic cleanup.

> `flowtract@0.1.0` is a developer preview. It is not a production-readiness or
> enterprise-readiness claim.

Start with the [five-minute quick start](quick-start.md), then read the
[core guide](guide.md), [error catalog](troubleshooting.md), and
[security and compatibility boundary](security.md).

The [market-gap proof](market-proof.md) contains three reproducible workflows
and a factual comparison with responsibilities projects otherwise own around
raw HTTP or Playwright request primitives.

## Evaluate the developer preview

Gate 4B is preparing a five-repository external cohort. Use the
[evaluation guide](evaluate.md) to run the dedicated registry-backed starter,
adapt one real authenticated workflow, and submit privacy-safe evidence. The
cohort evaluates product value and developer experience; it does not claim
production readiness.
