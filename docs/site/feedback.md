# Gate 4B feedback

Gate 4B invites TypeScript QA and backend teams to run the
[dedicated starter](https://github.com/flowtract/flowtract-starter), try one
real authenticated workflow and, if useful, a second workflow. Start with the
[evaluation protocol](evaluate.md).

Useful evidence includes time to first success, where maintainer help was
needed, defects, missing capabilities, repeated use, and support effort. Never
submit credentials, private source, endpoint data, or identifiable operational
details without authorization.

Flowtract collects no product telemetry or analytics.

Use the structured
[evaluation form](https://github.com/flowtract/flowtract/issues/new?template=gate4b-evaluation.yml),
[Q&A](https://github.com/flowtract/flowtract/discussions/categories/q-a), or
[Ideas](https://github.com/flowtract/flowtract/discussions/categories/ideas).
