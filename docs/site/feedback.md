# Gate 4B feedback

Gate 4B invites TypeScript QA and backend teams to try one real authenticated
workflow and, if useful, a second workflow. Feedback is opt-in through GitHub
issues or discussions.

Useful evidence includes time to first success, where maintainer help was
needed, defects, missing capabilities, repeated use, and support effort. Never
submit credentials, private source, endpoint data, or identifiable operational
details without authorization.

Flowtract collects no product telemetry or analytics.
